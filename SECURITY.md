# Security

Clasp reads files from other apps and people: `.pkpass` passes, Google Wallet exports and backups. If you find a way to make Clasp crash, leak data, write outside its own storage or reach the network when it shouldn't, please report it privately.

**How to report:** use [Report a vulnerability](https://github.com/pxgray/clasp/security/advisories/new) on this repository's Security tab. Please don't open a public issue for security problems.

Include the Clasp version (Settings → About), your Android version, and a file or steps that reproduce the problem. If a file holds real personal data, describe it instead of attaching it.

Only the latest release is supported. You should hear back within a week.
